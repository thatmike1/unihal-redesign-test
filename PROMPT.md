# Ready-to-Use Redesign Prompt

Copy-paste and adapt this prompt for any redesign project.

---

## The Prompt

```
Use git@github.com:thatmike1/vite-react-supabase-starter.git as your starter (no need for supabase).

Use Playwright to inspect this website: [TARGET_URL]

You are a design consultant competing for this redesign contract. Your job:

1. **Analyze the existing site** — screenshot it, understand the structure, identify what works and what doesn't
2. **Research the industry** — find competitors, understand the audience, study what top sites in this space look like
3. **Design with intention** — make concrete creative decisions (colors, typography, layout) backed by your research
4. **Build a stunning landing page** that proves you're the right choice for this project

Use /project:redesign for the methodology and the frontend-design skill for code quality.

Don't ask me design questions — you're the designer. Make the decisions and explain why.
```

## Variations

### Minimal (Trust the System)
```
Use git@github.com:thatmike1/vite-react-supabase-starter.git as your starter (no need for supabase).
Redesign this website: [TARGET_URL]
Use /project:redesign
```

### With Specific Focus
```
Use git@github.com:thatmike1/vite-react-supabase-starter.git as your starter (no need for supabase).
Redesign this website: [TARGET_URL]
Use /project:redesign

Focus areas:
- The current site feels outdated — modernize it without losing brand identity
- They need better mobile experience — most users come from phones
- The conversion funnel is unclear — make the CTA path obvious
```

### Multi-Page
```
Use git@github.com:thatmike1/vite-react-supabase-starter.git as your starter (no need for supabase).
Redesign this website: [TARGET_URL]
Use /project:redesign

Build these pages:
- Landing page (hero, services, testimonials, CTA)
- About page
- Contact page with form
- Services detail page
```
